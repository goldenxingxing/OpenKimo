OpenKimo · 使用指南

一个浏览器标签页，
驱动会写代码、能跑任务的 AI Agent

OpenKimo 是开箱即用的 AI Agent 平台：桌面一键安装或一条命令部署，在网页里创建会话，让 Agent 替你读写文件、执行命令、分析数据、调研网页——而不仅仅是聊天。

OpenKimo 是什么

不是聊天窗口，而是一个有手有脚的工作台

传统 AI 聊天只能「说」；OpenKimo 的 Agent 能「做」。每个会话背后是一个完整的运行时：Shell 命令执行、文件读写、网页搜索与抓取、后台长任务、子 Agent 分工，以及数百个开箱即用的技能（文档生成、数据可视化、代码审计等）。

你用自然语言描述目标，Agent 自己拆解步骤、调用工具、汇报结果。支持 OpenAI、Anthropic 等多家模型，随时切换。

三种使用形态

按场景选择，功能同源

个人推荐

桌面应用

macOS DMG / Windows 安装器，拖拽即装、零依赖。菜单栏/托盘常驻，浏览器自动打开操作界面。

团队推荐

Docker 部署

docker compose up -d 一条命令。每个会话独立沙箱容器，多用户、权限控制、资源限额。

开发调试

本地模式

无 Docker 直接在宿主机运行，适合开发者调试与快速验证，不建议生产使用。

快速上手

桌面版三步开始工作

  1. 安装 — 从 Releases 页面下载对应平台的安装包：macOS 选 arm64（Apple 芯片）或 x86_64（Intel），Windows 直接运行安装器。
    macOS 首次打开如提示未验证开发者：右键 App 图标 → 打开。
  2. 配置模型 — 首次启动弹出 Settings 窗口，填入至少一个 LLM API Key（Kimo / OpenAI / Anthropic），保存。
    之后随时可从菜单栏（mac）或托盘图标（Windows）右键打开 Settings 修改。
  3. 开始会话 — 菜单栏图标变为 ● Running 后浏览器自动打开 http://127.0.0.1:5494。选择工作目录，新建会话，用自然语言下达任务。

Docker 部署（团队 / 服务器）

shell
# 1. 下载配置文件
curl -O https://raw.githubusercontent.com/goldenxingxing/OpenKimo/main/docker-compose.yml
curl -O https://raw.githubusercontent.com/goldenxingxing/OpenKimo/main/.env.example
cp .env.example .env
# 2. 编辑 .env，填入至少一个 LLM API Key
# 3. 启动（自动拉取预构建镜像）
docker compose up -d
Docker 部署默认账号 admin / admin123，首次登录后请立即在 /admin 管理后台修改密码。

日常使用

把它当作一位可以布置任务的同事

会话与工作目录

每个会话绑定一个工作目录——Agent 读写文件都发生在这里。建议按项目建会话：代码仓库、数据文件夹、写作目录各开各的。

下达任务的技巧

直接说目标，不必拆步骤：「找出这个仓库里所有没被测试覆盖的公共函数并补上测试」比「先列出文件，再……」效果更好。任务大时 Agent 会自己规划、并行调用工具，长任务会转入后台执行并在完成时通知。

技能与扩展

内置数百个技能（写文档、做图表、审计代码、生成演示文稿等），会话中自动按需调用；也可以安装自定义技能包、接入 MCP 工具、通过 YAML 定义专属 Agent（限定工具集与系统提示词）。

六个使用案例

来自真实工作流的任务示例

代码工程

开发者 · 在代码仓库目录开会话

读懂陌生仓库、修 Bug、补测试、重构、写提交信息。Agent 会实际运行测试验证自己的修改，而不是只给建议。

这个报错日志在附件里，帮我定位根因并修掉，改完把相关测试跑一遍确认没有回归。
用到：Shell · 文件读写 · 代码搜索 · 后台任务

数据分析与报告

运营 / 分析师 · 在数据文件夹开会话

清洗 CSV、跑统计、画图表、产出带结论的 PDF / Word 报告。Docker 版沙箱内置 Jupyter 内核，代码即写即跑。

把 orders.xlsx 里的退货数据按品类和月份交叉分析，找出退货率异常的品类，产出一页 PDF 摘要给管理层。
用到：Jupyter / Python · 数据可视化技能 · 文档生成技能

网页调研与信息收集

产品 / 市场 · 任意会话

搜索、抓取、比对多个网页，输出结构化调研结论。Docker 版沙箱自带无头 Chromium，可访问需要渲染的页面。

调研这 5 家竞品的定价页，整理成一张对比表：套餐档位、计费方式、免费额度，注明信息来源链接。
用到：网页搜索 · 网页抓取 · 无头浏览器

文档与写作

任何角色 · 在写作目录开会话

论文、报告、周报、邮件、演示材料。写作类技能内置常见文体的结构规范，产出的是排好版的成品文件。

根据这周的会议纪要（目录里三个 md 文件）写一份项目周报，重点讲风险项，导出成 docx。
用到：写作技能 · docx / pdf 生成 · 文件读写

批量自动化

效率型用户 · 长任务转后台

批量重命名、格式转换、图片处理、多文件内容替换。任务可拆给多个子 Agent 并行，主会话继续响应你。

把 photos/ 下 800 张图片按拍摄日期归档到子文件夹，统一转成 webp，超过 2MB 的压缩到 2MB 以内。
用到：后台任务 · 子 Agent · Shell

团队共享 Agent 平台

小团队 / 企业 · Docker 部署

一台服务器供全团队使用：每人独立账号与会话，互不可见；管理后台管理用户；每会话独立容器沙箱，CPU / 内存 / 磁盘限额，代码永不触碰宿主机。支持从管理面板定制 Logo 与品牌（OEM / 私有化）。

用到：多用户与权限 · 会话沙箱 · 资源限额 · 品牌定制

配置速查

桌面版在 Settings 窗口配置；Docker 版通过 .env

配置项说明
LLM Provider可同时配置多个（Kimo / OpenAI 兼容 / Anthropic），指定其一为默认，随时切换
API Key / Base URL / 模型名每个 Provider 独立配置，支持自定义网关地址与上下文长度
Thinking / Temperature是否展示思考过程、生成温度
Web 端口默认 5494
Session Token为 Web 界面加访问令牌（局域网共享时建议开启）
沙箱资源限额Docker 版：每会话 CPU（默认 2 核）、内存（默认 4G）等
